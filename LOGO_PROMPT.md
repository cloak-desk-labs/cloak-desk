# CloakDesk Logo Design Prompt

## Main Prompt

A sleek, modern logo for "CloakDesk" - a privacy-first blockchain dashboard. The logo should feature a stylized cloak or shield icon combined with subtle blockchain/cryptographic elements. Design style: cyberpunk, minimalist, tech-forward. Color scheme: gradient from cyan/teal (#06b6d4) to violet/purple (#7c3aed), with electric purple accents (#8b5cf6). Dark background (#0b0f14). Include subtle neon glow effects. The design should convey privacy, security, and cutting-edge technology. Icon should work well at small sizes. Typography: modern, clean sans-serif (Inter font family). Style: flat design with gradient fills, subtle shadows, and neon edge lighting.

## Detailed Prompt (for AI Image Generators)

```
Create a professional logo design for "CloakDesk" - a privacy-first blockchain privacy dashboard application. 

VISUAL ELEMENTS:
- Primary icon: A stylized cloak or shield shape with subtle blockchain/network connection nodes integrated
- Alternative: A shield with cryptographic lock elements, or a cloak with digital/tech patterns
- The icon should be geometric yet organic, suggesting both protection and technology
- Include subtle circuit-like patterns or network connection lines within the design

COLOR PALETTE:
- Primary gradient: Cyan/Teal (#06b6d4) transitioning to Violet/Purple (#7c3aed)
- Accent color: Electric Purple (#8b5cf6)
- Background: Deep dark blue-black (#0b0f14)
- Optional highlights: Success green (#10b981) for positive elements

STYLE & AESTHETICS:
- Cyberpunk aesthetic with modern minimalist approach
- Clean, flat design with gradient fills
- Subtle neon glow effects around edges
- Glassmorphism-inspired transparency effects (optional)
- Tech-forward, cutting-edge appearance
- Professional yet edgy

TYPOGRAPHY:
- Modern, clean sans-serif font (Inter-style)
- "CloakDesk" text should complement the icon
- Font weight: Medium to Semi-bold
- Letter spacing: Slightly tight for modern feel

TECHNICAL REQUIREMENTS:
- Scalable vector design (SVG-friendly concept)
- Works well at small sizes (favicon scale)
- High contrast for visibility
- Monochrome version possible
- Icon should be recognizable without text

MOOD & FEELING:
- Privacy and security
- Cutting-edge technology
- Blockchain/cryptocurrency
- Stealth and anonymity
- Professional dashboard tool
- Trustworthy yet innovative

AVOID:
- Overly complex details that won't scale down
- Cliché padlock or key icons
- Too aggressive or intimidating appearance
- Outdated design trends
- Cluttered or busy compositions
```

## Design Principles

1. **Simplicity**: Clean, uncluttered design that works at any size
2. **Relevance**: Clearly relates to privacy, security, and blockchain
3. **Memorability**: Distinctive and recognizable
4. **Versatility**: Works in color, monochrome, and various contexts
5. **Modern**: Contemporary design that won't feel dated quickly
6. **Brand Alignment**: Matches the cyberpunk, tech-forward aesthetic of CloakDesk
